About the free beta

This first version provides preference-based recommendations and guided travel help in multiple languages. It is not yet connected to a large language model, live travel inventory or a booking engine. Translation is provided through MyMemory when available and has daily usage limits; if translation is unavailable, the assistant will show its answer in English. A full generative AI connection can be added later using a free-tier provider key stored securely on a backend.

Traveller preferences are stored in your browser on this device. For secure sign-in and syncing across devices, the separate account page needs the TRAVORA cloud project to be configured. Do not use this beta as a substitute for official visa, safety or medical advice.
