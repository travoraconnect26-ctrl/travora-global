About TRAVORA
TRAVORA is an independent travel discovery project being developed to help travelers explore destinations and find useful travel options through established booking partners.

Affiliate disclosure: Some links may eventually be affiliate links. If you book through an approved partner link, TRAVORA may earn a commission at no extra cost to you.

Important: The country directory covers 195 countries using the common international count (193 UN member states plus the Holy See and Palestine). Country cards include reference capitals, native names, currency names and codes, languages and calling codes. The interactive world map contains 34,480 unique locations: 195 country reference points, 34,248 populated places, 15 island locations and 22 attractions. City markers load as visitors zoom, search or choose the Cities filter. The Worldwide Cities Directory lets visitors search 34,248 populated places by name, country and region, with administrative areas, coordinates, time zones, population references and map links. The Detailed Guides library contains 253 editorial destination profiles covering regional geography, signature experiences, food culture, transport, trip planning and responsible travel. These 253 guides are curated in-depth profiles, not a claim that every city or attraction has its own full editorial guide. This is an informational directory, not a live booking service. Live prices, availability, reservations and payments are not currently connected. Country names, capitals, currencies and languages are adapted from the Annexare Countries dataset (MIT licence). Population, area, subregion, timezone and centroid fields include adapted data from the Countries States Cities Database (ODbL 1.0, including share-alike obligations). Populated-place data is from GeoNames (CC BY 4.0). See data sources and licences. All are static reference snapshots, not official government advice. Always confirm travel details with the relevant provider.
